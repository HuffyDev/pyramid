# PYRAMID — every coin is a brick.

A non-custodial Solana launchpad. Every coin launched through it becomes a brick in a live pyramid:
the first launch is the apex, new launches land in the bottom row, dead coins crack but never disappear.
The $PYRAMID token is the capstone.

See [SETUP.md](SETUP.md) for env vars, Replit and the go-live checklist.
